## Structs and Shared Structs for Stage 2

- wiki: [Shared structs](../../proposals/shared-structs.md)

- slide: [link](https://docs.google.com/presentation/d/1_LOkmaeM0S-VOvhJ28eeDJUmkMeHVyltxSt1lGLF5iA/)

The conclusion was Stage 2 with the reviewer slate and open questions recorded.

## Porffor JS engine

[OMT](../../people/OMT.md) presented Porffor, a from-scratch JavaScript engine written in JavaScript that compiles ahead-of-time to WebAssembly (or native), trading away JIT warm-up and `eval` for small binaries and sandboxing. It passes around 50% of Test262. The engine is an independent implementer's perspective brought to TC39.

The conclusion was no action — an informational presentation with a live demo.

## JSSugar/JS0

- slide: [link](https://docs.google.com/presentation/d/1ylROTu3N6MyHzNzWJXQAc7Bo1O0FHO3lNKfQMfPOA4o/edit)

[SYG](../../people/SYG.md) presented the problem statement behind a two-layer language: the cost of complexity in JavaScript (security, performance, stability) falls on users and is no longer offset by the value of new features, and engines have grown more conservative. The pitched direction is JS0 — the language engines implement — plus JSSugar, features that live in tools and compile to JS0. Reaction was mixed: [WH](../../people/WH.md) questioned whether complexity is really held constant, and [NRO](../../people/NRO.md) noted tool maintainers are underfunded. No consensus was sought or reached; the discussion was set to continue, and the repo would be made public.

The conclusion was no consensus — discussion to continue (see the [day 3 continuation](2024-10-10.md)).

- slide: [link](https://docs.google.com/presentation/d/1Z-DQ3bNjrbhrPhJ9PMEjTtZr0tlXiN14REvtcPocdGM/edit?usp=sharing)

- proposal: [Ecma-402 PR 925](https://github.com/tc39/ecma402/pull/925)

[BAN](../../people/BAN.md) presented three ECMA-402 PRs: #919 makes `RelativeTimeFormat`/`DateTimeFormat` honor a specified `numberingSystem` (aligning the spec with what browsers actually do), #918 makes the plural-category order deterministic (zero, one, two, few, many, other), and #925 restricts currency minor-digit defaults to standard notation. The conclusion was conditional consensus on all three PRs, pending Mozilla's review.
